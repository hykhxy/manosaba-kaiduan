# 魔法少女的魔女审判 · 开端（非官方同人网页）

《魔法少女ノ魔女裁判》同人互动开端：标题页 + 创造角色 + 角色图鉴 + 世界观介绍。纯静态、零依赖、无构建，GitHub Pages 直接托管。

在线地址：https://hykhxy.github.io/manosaba-kaiduan/

## 功能

- **标题页**：1270×720 画布等比缩放，与开场视频逐像素对齐；左侧菜单为「创造角色 / 角色图鉴 / 世界观介绍」，右侧为读档、音乐、官方站、Bangumi、说明。窄屏自动改成大按钮菜单。
- **创造角色**：左侧立绘（本地上传 / 外部链接 / 从图鉴选取），姓名、性别、性格、身份（是否魔女；是则填魔法、效果、限制、原罪）、开局时间线与开局地点（19 处）、天赋（120 个，4 个等级，每个效果 ≥ 50 字；一、二级无代价，三、四级有代价）。
  - 「保存」：点击即写入本机浏览器存储。
  - 「创造答案」：弹出整理好的完整设定，点击文字框即可复制。
- **角色图鉴**：十三位囚犯 + 月代雪 + 典狱长 + 看守，官方立绘全身原画，含编号、声优、生日、身高体重、原罪、魔法、外貌、性格、背景、口癖、关系、时间线、结局。
- **世界观介绍**：总纲、魔女因子、残骸与特雷德基姆、五大铁则、死亡回溯与魔女安息仪式、审判玩法、三个周目与五条开局线、魔女语言与音乐、十九处地点、势力与派系，配官方截图。

## 图片来源与线路

立绘与截图**一律外链，不入库**：

| 内容 | 主线路 | 降级线路 |
|---|---|---|
| 角色立绘 | Bangumi `lain.bgm.tv` | wsrv.nl → images.weserv.nl → 占位+原图链接 |
| 世界观截图 | Steam `shared.akamai.steamstatic.com` | Steam 国区 CDN `shared.cdn.queniuam.com` → Fastly → wsrv.nl |

每条线路 9 秒超时自动切下一条；全部失败时显示占位并给出原图链接。
